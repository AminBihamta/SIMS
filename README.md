# SIMS: Inventory and Club Management System

SIMS (SEMESRA Inventory Management System) is a comprehensive platform for managing inventory and club activities specifically designed and developed for SEMESRA, a school in Malaysia. It streamlines equipment tracking, club membership, financial records, notifications, and reporting.

## Features

- Equipment and inventory management
- Club creation and member management
- Borrowing and return tracking
- Financial record keeping
- Automated notifications and reminders
- Reporting tools for clubs and inventory
- Vendor management

## Usage

SIMS is designed for easy use by administrators, supervisors, and club members. Access the web interface to manage inventory, clubs, and related activities. No special setup is required—just deploy and start using.

## Tech Stack

- Ruby on Rails (backend & MVC framework)
- JavaScript for client-side interactivity
- PostgreSQL (database)
- HTML5 & CSS3

## Role Based Access

SIMS supports multiple user roles to ensure secure and appropriate access:

- **Administrator:** Full access to all features, user management, and system settings.
- **Supervisor:** Can manage clubs, approve borrowings, and oversee inventory.
- **Club Member:** Can request equipment, view club information, and receive notifications.

Each role has tailored permissions and views to maintain data integrity and security.
